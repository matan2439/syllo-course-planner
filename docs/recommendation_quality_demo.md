### 1.4 Before / After — what enrichment changes

**Before enrichment (Stage 1 — keyword-only scores):**
- Scores come from `capability_assignments` stored in the board JSON
- Only courses whose names/keywords explicitly mention VLSI/DSP get non-zero scores
- Courses covering implicitly relevant material (e.g., a signal processing course taught via filter design) receive 0

**After enrichment (Stage 2 — LLM syllabus extraction):**
- Each course's `syllabus_summary_he`, topics, prerequisites, assessment, and structure are fed to the LLM
- The extraction maps course content to the 24-capability ontology with evidence spans
- Implicit relevance is captured: a VLSI course covering power-minimisation layout techniques earns `vlsi: 0.7` from the syllabus body, not just from its name
- Evidence is validated against `extractionContent` (7-field superset) so citations from the prerequisites field are accepted — this was the bug fixed in this PR
- The validator rejects unsupported claims and routes unknown hashes to immediate rejection

**Genuine improvement vs. internal scoring changes:**
- Stage 2 adds courses that had `0` fit before because their syllabus content (not title) reveals relevance
- Stage 2 may lower scores on courses whose enriched content contradicts the keyword-based assignment
- The `extractionHash` path ensures that the evidence backing each score change is a verbatim excerpt from the official syllabus — not an LLM hallucination

## 3. Remaining irrelevant recommendations

**Current limitations (Stage 1 baseline):**

1. **ME cross-specialization leakage**: since only 2 ME courses have non-zero `fluids` scores, the fluids plan cannot currently prefer fluids electives over design electives — it places what it must. This is the highest-priority gap Stage 2 addresses.

2. **EE VLSI plan includes `0512-4264` (Intro to Statistical Machine Learning)**: this appears in the VLSI plan because ML is adjacent to digital design tools but is not a core VLSI course. Post-enrichment, the LLM would assign a lower VLSI score based on the syllabus body, allowing the planner to prefer `0512-4165` (Bipolar devices for VLSI) instead.

3. **SP plan includes `0512-4820` (Space Systems Engineering)**: the keyword `space` has an accidental overlap with `signal_processing` via RF links. Syllabus extraction would route this to `communication_systems` rather than `signal_processing`, removing it from an SP-focused plan.

4. **SP-related courses with score 0**: Several courses on adaptive filtering and spectral estimation have no keyword match but cover core DSP material. Stage 2 would surface these.
