# EE validation completion

The target is a fully editable, verified degree in the live planner, with the same
workflow reusable for another degree. Preserve saved plans and restore academic drafts
with warnings. Never clear the public readiness banner by hiding an unsupported rule.

## Implemented foundation

- Registry-scoped IMS collection retains every discovered group/term, raw responses,
  source inventories, hashes and original fetch dates. Builds re-parse captures.
- Shared bounded AND/OR evaluation reaches profiles, placement, reachability and
  preflight checks. Unknown evidence warns in manual drafts and blocks certification.
- Exact early-year completions contribute to the later planner without becoming
  schedulable courses there.
- Shared student evidence supports cohort, average, English recognition, course dates,
  scoped extension decisions, committee-set graduate thresholds and separate approvals.
- Core matching, personal-condition definitions and optional high-current pathway data
  have release checks. Both window boards preserve every definition.
- Canonical skill references describe these contracts and the narrative-source audit.
- The additional-lab branch checks a cited credit allocation and independently verifies
  sufficient credit without the non-theory labs, while preserving actual workload.
- Technician exemptions require individual full-credit awards after the published
  credential/exam checks. Enrollment, completion and exemption credit are deduplicated.
- Supplemental recognition separates enrollment approval from earned credit, preserves
  a valid track/core baseline, and keeps external credit separate from catalog identity.
- Both window catalogs supply their graph, track pool and full mandatory-course years.
  Failed source refreshes retain old evidence and fail rather than forging freshness.

## Remaining implementation and acceptance

1. **Conditional prerequisites.** Model the published reserve-duty and eligible-parent
   conditions with explicit, scoped student evidence. Apply exceptions consistently
   to OR branches, timing, generation and validation. An arbitrary approval must not
   waive unrelated requirements. Complete release verification for the ordinary
   before-or-concurrent policy and attendance/exam-eligibility records.
2. **Window versus degree completion.** Retain all rules in both windows, but explicitly
   distinguish completing a two-year window from graduating. Global core/lab/language
   minima must remain visible without falsely implying they must be completed by year 2.
   Placement legality, draft navigation and whole-degree certification are separate.
3. **Release verification.** Run the live source/freshness check; investigate every
   remaining rule or source conflict. Test the deployed editable preview across both
   windows, evidence reload, manual edits, saved alternatives and ME regression. Only
   promote academic status and remove the broad banner when the release gate passes.
